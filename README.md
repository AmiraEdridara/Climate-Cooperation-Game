# Climate Cooperation Game

An interactive climate cooperation game theory simulation that explains the prisoner's dilemma through global emissions choices.

The site lets users:

- Explore how abate, emit, and tit-for-tat strategies affect global outcomes
- Run a forward simulation from 2025 to 2100
- View major emitters on a world map
- Compare simplified game theory outcomes with historical emissions data from 1990 to 2023

## Project Structure

- `index.html` - page structure and content
- `styles.css` - visual styling and responsive layout
- `script.js` - simulation logic, map rendering, and historical charts

## How To Run

Open `index.html` in a browser.

The world map uses external CDN resources for D3, topojson, and world-atlas data, so an internet connection is needed for the map to load.

## Data Notes

Historical comparison figures are based on publicly reported emissions, atmospheric CO2, and temperature datasets. Forward simulation values are simplified for educational clarity.
